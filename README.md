KO-of-MDD-Risk-Genes-in-vivo
These notebooks contain code reproducing the single-cell analyses from:

Liansheng Zhang1, Xiangrui Kong, Qi Ma1, Xinde Hu, Shicheng Cai1, Bo Wang, Weijuan Zou, Tao Bai, Meimei Zhang, Liu Fan, Runlin Tan, Ziji Dai, Zhiheng Jia, Tianwen Li, Xingyu Liu, Huatai Xu, Jianrong Wu, Yuanyi Zheng, Zhengzheng Xu, and Haibo Zhou, "Dissecting the genetic risk of major depressive disorder reveals a disease-linked gene cluster via in vivo Perturb-seq", Nature Genetics, 2025

We provide info on:
How to define cells with MOI=1; please refer to the sg_assignment directory for details.

In this directory, we demonstrated the MOI calculation workflow for one of the reactions. Other reactions can be processed similarly. Briefly, since our project adopts a dual-sgRNA mode for KO Perturb-seq, we define MOI=1 cells primarily based on cells defined by sg2, and then remove cells with multiple sg1 assignments. For details, refer to Step 4: "Identify confident MOI=1 cells and assign guides" in the sg_assignment.Rmd within that directory.

(Note: It is important to emphasize that this part of the analysis is largely based on the analytical code from the AAV-Perturb-seq project published in Nature by Santinha, A.J, et al. in 2023. More specifically, refer to https://github.com/plattlab/AAV-Perturb-seq. We strongly recommend familiarizing yourself with their scripts and rationale first.)

After defining MOI=1 cells, all subsequent analyses are built upon this foundation.

Application 1:
How to perform gene co-expression network analysis [to reproduce Fig. 2a-2c and Extended Data Fig. 6b-6m]

This part of the analysis was conducted following the online protocol for hdWGCNA (for more details, see https://smorabit.github.io/hdWGCNA/index.html). Specifically, we used only MOI=1 cells as the input data, focusing primarily on neuron cells. The analysis strictly adhered to the parameters and example code provided in the hdWGCNA protocol.

Upon completion of this analysis, the results generated will correspond to Figure 2a, 2b, and Extended Data Fig. 6b-6c. Furthermore, the analysis will yield the enrichR annotation results shown in Extended Data Fig. 6d-6m. These enrichment results for GO pathways can then be visualized using ggplot2. For specific implementation details, please refer to the script hdWGCNA.analysis.r located in the hdWGCNA_MDD_risk_genes_perturbation_with_Module directory.

To investigate the perturbation effect of each perturbed gene relative to the control across different gene co-expression modules, we performed a deeper analysis of how these perturbations affect the activity of individual modules. This specific analysis is implemented in the script MDD_risk_gene_knockout_on_module_activity.r, also located in the hdWGCNA_MDD_risk_genes_perturbation_with_Module directory. The results from this analysis correspond to Figure 2c.

Application 2:
How to perform specific pathway similarity analysis of MDD risk gene perturbations [to reproduce Fig. 2d-2f]

This analysis is primarily based on the DEGs (Differentially Expressed Genes) derived from comparing MDD risk gene perturbations versus control within the MOI=1 cell population. The methodological framework is built upon the DEG analysis code from the AAV-Perturb-seq project published by Santinha, A.J, et al. in Nature (2023). We strongly recommend first familiarizing yourself with their scripts and analytical rationale. For reference, a demonstration code example is provided in the directory: specific_pathway_cluster_analysis/DEGs_demo_data_and_code/.

Upon obtaining the DEG files, the analysis proceeds with the following shell and R code:

• Shell Script: 2025-6-18.specific_pathway.correlation.sh

• R Script: specific-pathway.r

Key Steps in the Analysis:

1.  Data Preparation: The DEG files for each MDD risk gene perturbation (compared to control) are loaded and consolidated.
2.  Pathway Extraction: Specific pathways of interest are extracted from databases such as KEGG, GO, or Reactome. The selection is focused on pathways relevant to MDD pathophysiology and neuronal function.
3.  Similarity Calculation: For each MDD risk gene perturbation, the enrichment scores or regulation patterns (e.g., Z-scores of pathway members, direction of DEGs within the pathway) across these specific pathways are computed.
4.  Correlation Matrix Construction: A similarity matrix (e.g., Pearson correlation matrix) is generated by comparing the pathway regulation profiles of every pair of MDD risk genes. This reveals which genes perturb similar biological processes.
5.  Clustering and Visualization: Hierarchical clustering is applied to the correlation matrix to group MDD risk genes that share similar pathway perturbation signatures. The results are visualized using a clustered heatmap (Fig. 2d), which may be complemented by network graphs (Fig. 2e) and bar plots showing top enriched pathways for key clusters (Fig. 2f).
6.  Validation and Interpretation: The biological coherence of the identified clusters is assessed through functional enrichment analysis and literature review to link shared pathway perturbations to known MDD mechanisms.

This approach systematically maps the functional convergence and divergence of MDD risk genes at the pathway level, providing insights into shared pathogenic mechanisms and potential therapeutic targets.


Application 3:
How to identify neuron cell subtype-specific DEGs [to reproduce Figure 2g-2h]

The analysis begins by identifying neuronal cell subtypes—specifically excitatory and inhibitory neuronal subpopulations—based on established marker genes. This classification is visually detailed in Extended Data Fig. 9a-9b.

Once neuronal subtypes are annotated, the next step involves calculating subtype-specific Differential Expressed Genes (DEGs). For each neuronal subtype, DEGs are identified by comparing cells with MOI=1 that contain sgRNAs targeting an MDD risk gene (to achieve knockout) against control cells (e.g., cells expressing non-targeting control sgRNAs or just a fluorescent reporter).

The computational method for DEG detection follows the pipeline established by Santinha, A.J., et al. in their 2023 Nature paper on AAV-Perturb-seq. For implementation details, refer directly to their code repository:
https://github.com/plattlab/AAV-Perturb-seq
Alternatively, you can use the demonstration datasets and scripts provided in Application 2 of this repository as a reference.

After generating the DEG lists for each neuronal subtype, the final step is to identify and visualize subtype-specific DEG signatures resulting from the genetic knockouts. This is achieved using the script get_specific_DEGs.r located in the directory:
subcell_specific_DEGs_in_Ex_neuron_and_In_neuron/
This script processes the DEG outputs to:
•   Compare the knockout-induced DEG profiles across excitatory and inhibitory neuronal subtypes.

•   Identify genes that are differentially expressed in a subtype-specific manner as a consequence of the MDD risk gene knockouts.

•   Generate the figures (Figure 2g-2h) that highlight these cell-type-specific transcriptional responses to genetic perturbation.

This multi-step approach ensures a rigorous, reproducible analysis of how knockout of MDD risk genes distinctly affects transcriptional networks in specific neuron subtypes, revealing potential cell-type-specific mechanisms in disease pathophysiology.


Application 4:
How to cluster and reduce dimensionality of 44 MDD risk genes' perturbation in neurons [to reproduce Fig. 3a and Extended Data Fig. 7f]

The perturbation_clustering directory within this repository provides the core scripts for this analysis:
• direct_cluster.rmd

• umap_cluster.rmd

These codes are designed to process the perturbation signatures of the 44 MDD risk genes within neuronal populations. The analysis typically involves:
1.  Data Integration: Compiling the transcriptional perturbation profiles (e.g., DEG lists or normalized expression changes) for all 44 MDD risk gene knockouts.
2.  Dimensionality Reduction: Applying techniques like UMAP (Uniform Manifold Approximation and Projection) to project the high-dimensional perturbation data into a two-dimensional space for visualization, effectively revealing the overall structure and relationships between different genetic perturbations.
3.  Clustering Analysis: Employing clustering algorithms (e.g., hierarchical clustering, k-means) on the perturbation profiles to identify groups of MDD risk genes that elicit similar transcriptional responses in neurons. These groups may indicate shared functional pathways or biological mechanisms.
4.  Visualization: Generating the plots for Figure 3a and Extended Data Fig. 7f, which visually represent the clustering results and the low-dimensional embedding of the perturbations.

Application 5:
How to map mouse perturbation data back to MDD patients' single-cell data [to reproduce Fig. 3g]

This cross-species integration analysis is facilitated by scripts in the Seurat_v5mapQuery_MDD_and_mouse_MDD_risk_gene_KO directory:
• Seurat_v5mapQuery.analysis.sh

• get_mapped_cell.r

The process leverages the Seurat v5 mapQuery() function for reference-based integration and typically includes:
1.  Reference Construction: Using the human MDD patient single-nucleus RNA-seq data as a reference atlas.
2.  Query Mapping: Projecting the transcriptional profiles of mouse brain cells, perturbed by MDD risk gene knockouts (from Application 4), onto the human reference. This step aims to find the closest correlating cell states or subtypes within the human MDD dataset for each mouse perturbation profile.
3.  Analysis & Interpretation: The script get_mapped_cell.r is then used to analyze the mapping results, quantifying how well each mouse perturbation profile aligns with specific cell states or conditions in the human MDD data. The output generates Figure 3g, which illustrates the mapping relationships and potential conservation of perturbation responses across species.

Application 6:
How to correlate six MDD risk genes in mouse neurons to MDD patients [to reproduce Fig. 6e-f and Extended Data Fig. 12b-g, and j]

The correlation analysis between specific mouse perturbations and human patient data is implemented in the MDD_patients_correlation_analysis directory via the script:
• MDD_correlation_with_mouse_pool_screening.sh

This analysis involves:
1.  Focus Selection: Concentrating on a subset of six MDD risk genes (cluster1) based on prior results (e.g., from Applications 4 and 5).  
2.  Human Gene Expression Profiling: Extracting normalized expression profiles of human orthologs of the six genes from snRNA-seq data of MDD patients.  
3.  GSEA Enrichment Analysis: Evaluating whether DEGs from MDD patients compared to healthy controls show enrichment in the Oxytocin signaling pathway through GSEA.  
4.  Visualization and Validation: Generating GSEA enrichment plots for Figure 6e-6f and the series of analyses in Extended Data Fig. 12b-g, and j, which provide evidence supporting the potential clinical relevance of the findings from the mouse model.


Special Note:

This project did not develop new algorithms and primarily utilizes previously published methods. For more detailed research, please refer to the repositories of the published methods:

• snRNA-seq analysis is based on Hao et al., 2023 (https://satijalab.org/seurat/).

• Count tables for gRNA expression libraries are generated as shown in Hill et al., 2018 (https://github.com/shendurelab/single-cell-ko-screens.git).

• MOI calling and DEGs analysis are based on Santinha, A.J., et al., 2023 (https://github.com/plattlab/AAV-Perturb-seq).

• hdWGCNA analysis is based on Morabito et al., 2023 (https://smorabit.github.io/hdWGCNA/).

The analysis process for other array data is consistent with that of the pools data and is not provided here. For further inquiries, please contact us.
